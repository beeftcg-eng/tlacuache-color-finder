# Encuentra tu color: vista previa

Vista previa del buscador de color para [Con T de Tlacuache](https://tdetlacuache.com): una rueda de color que señala la pintura en existencia más parecida.

En esta vista previa las existencias y los precios son los del 21 oct 2026. Instalado en la tienda, el buscador los lee en tiempo real.
